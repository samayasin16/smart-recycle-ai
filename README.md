# ♻️ Smart Recycle AI

A real-time AI web app that classifies waste materials using deep learning and computer vision.

## 🚀 Demo
You can try the live app here:
👉 https://your-app-link.streamlit.app

---

## 📌 Features

- 📷 Upload up to 3 images for classification
- 🎥 Real-time live camera prediction
- ♻️ Classifies waste into:
  - Glass
  - Metal
  - Paper
  - Plastic
  - Shoes
- 📊 Confidence score for each prediction
- ⚡ Fast real-time inference
- 🧠 Deep learning model (CNN-based)

- TensorFlow / Keras
